# Account-Opening Checklist
## iStone / DFW Windows Plus / Metroplex Flat Metal

Use this when opening trade accounts. Goal: get **resale pricing**, **freight quotes**, and **warranty PDFs** before you buy.

---

## Documents to have ready (copy once, reuse everywhere)

| Document | Notes |
|---|---|
| Texas Sales & Use Tax Permit / resale certificate | Required for tax-exempt wholesale purchases |
| EIN / W-9 | Legal name must match bank and checks |
| Articles of organization / DBA filings | If buying under iStone vs Windows Plus vs Metroplex, open accounts under the entity that will invoice |
| Business license / contractor license | Some mills ask; have PDF ready |
| Certificate of Insurance (COI) | Often required for mill/dealer programs and jobsite delivery |
| Voided check or bank letter | For Net-30 applications |
| Trade references (3) | Other distributors, mills, or material suppliers you’ve paid |
| Credit references / personal guarantee | Common on first Net-30; start COD if needed |
| Showroom / warehouse address | 6512 Precinct Line Rd, Suite C, Hurst, TX 76054 |
| Phone for accounts payable | Same number or dedicated AP line |

**Tip:** Create one PDF packet named `Trade-Account-Packet-YYYY.pdf` and email it with every application.

### Week 3 — Truckload / importer backups
| Supplier | Category | Why | Typical ask |
|---|---|---|---|
| Europine | SPC / LVT truckload or container | Mix/match truckload programs | Retailer / truckload application |

## On every first quote, demand this comparison

For **the same job-ready spec**, ask for:

1. **Pallet price** ($/sf) + freight to Hurst  
2. **Truckload price** ($/sf) + freight to Hurst  
3. Wear layer (mil), core type (SPC/WPC), thickness, waterproof claim  
4. Matching trim / stair nose pricing  
5. Reorder lead time for the same lot/dye lot  
6. Warranty you can pass to the homeowner (PDF)  
7. Damage / shortage claim window  

Fill results into `02-price-book-template.csv`.

## Seconds / surplus buying rules

Before you pay:

- [ ] See photos of actual lot (not catalog photos)  
- [ ] Confirm grade: first-quality surplus vs B-grade  
- [ ] Confirm sq ft available and shade variation risk  
- [ ] Confirm you can sell as “Warehouse Special / Limited Lot”  
- [ ] Set max sell warranty (often labor-only or 1–5 yr materials)  
- [ ] Confirm you can move it in ≤60 days  

Never mix seconds into premium custom cabinet / shower / large-home brand jobs without disclosing.
